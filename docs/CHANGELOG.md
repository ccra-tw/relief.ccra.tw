# 版本紀錄

版本號 X.Y.Z＝升級服務．大修．小修；唯一來源是 `lib/version.php`，每次上線的改動同一個 commit 升版並在這裡記一筆。

## 0.3.0（2026-10-29）

- 新增「錄影簽名」雛形（/poc/，限同工角色）：物資簽收時手寫簽名＋錄一段聲明（最長 30 秒，手機瀏覽器即可），伺服器記錄簽名與錄影的 SHA-256 及存證碼，收執頁每次開啟都重新驗證是否被改過。附個資告知與同意、保存期限到期自動刪除、調閱留稽核紀錄。只放測試資料，不接正式資料表；合規（電子簽章法、數位簽章）待評估。

## 0.2.8（2026-10-28）

- 送名錄新增申請時，地址開頭改帶「【急難救助系統申請】」（照名錄管理者約定的辨識字樣；原本誤帶在地址結尾且字樣不同）。

## 0.2.7（2026-10-28）

- 修正：教會帳號編輯草稿或被退件的申請時一律存不進去（顯示「已送審的申請不能在這裡修改」），因為教會端為了看不到審核狀態而把狀態欄拿掉，儲存時卻拿那個欄位判斷。改讀原始資料列判斷（試用回饋：退件後改金額就無法再送審）。

## 0.2.6（2026-10-28）

- 新增／編輯申請：必填欄位沒填齊時，頁首明確顯示「尚未儲存」並列出要補的欄位；原本錯誤只標在各欄位旁，使用者會以為已經存了（走查前試用回饋）。

## 0.2.5（2026-10-27）

- 教會帳號登入頁不再被 M365 身分自動登入蓋過：協會同工按「登出」後可改用教會帳號登入（走查切換身分用）；登入頁另有「以 M365 身分進入」連結。

## 0.2.4（2026-10-27）

- 頁首協會標誌改照官網呈現成圓形徽章（白底圓＋細框），並避免被版面擠壓（熊哥回饋「Logo 變形」「Logo是圓的」）。

## 0.2.3（2026-10-27）

- 教會端看得到退件原因：清單上標「退件，請修改」，打開申請會顯示退件原因、退回的關卡與日期（教會帳號沒有 Email，收不到退件通知；熊哥 10-27 裁示）。其餘審核進度仍不給教會端看。

## 0.2.2（2026-10-27）

- 審核紀錄的「關卡」改顯示中文（教會牧者、區辦社工、他區社工、服管組），不再出現 pastor、region 等代碼。
- 撥款批次：區辦只顯示本區小計，不再看到其他區的金額。
- 待我審核（區辦社工）加「提早結案審核」入口，原本只能手打網址。

## 0.2.1（2026-10-27）

- 寬螢幕：頁首與內容對齊同一個置中欄位，內容欄放寬到 1240px（熊哥回饋「寬螢幕看的會很不舒服」）。
- 管理頁的區辦編輯欄位排成一行；勾選框靠左對齊，不再浮在欄位中間。

## 0.2.0（2026-10-27）

- 套用救助協會 CI：頁首放協會標誌與全名，標準色改為協會官網的橘與深灰（按鈕色再加深以符合 WCAG AA 對比）。
- 頁尾顯示系統版本、更新日期與版權宣告。
- 導覽列標示目前所在頁面；登出改為按鈕樣式；手機版導覽可橫向捲動。
- 首頁功能磚加一句說明。
- 個案清單與申請內容的狀態改顯示中文（例：「區辦社工審核中」）並以顏色標籤區分。
- 申請內容表格的分節列加底色，表單欄位聚焦時有明顯框線；申請人電話欄的必填星號不再換行。
- 個案清單、待我審核沒有資料時，顯示說明而非空表格。
